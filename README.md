# Учебный проект: Homework 21.2 Основы верстки (bootstrap)

Проект для отработки основ вёрстки (HTML + Bootstrap 5) и работы с простым HTTP‑сервером на Python.  
Сервер обрабатывает GET‑запросы и отдаёт статические HTML‑страницы: **Главная**, **Каталог**, **Категории** и **Контакты**. [web:256][web:259]

## Стек

- Python 3.13 (`http.server`, `BaseHTTPRequestHandler`)
- HTML5
- Bootstrap 5 (через CDN)
- Небольшое количество встроенного CSS в `<style>` блокаx

## Структура проекта

```text
my_website/

├── server.py         # HTTP-сервер, раздающий HTML-страницы
├── index.html        # Главная страница
├── catalog.html      # Каталог товаров
├── category.html     # Страница категорий
├── contacts.html     # Контакты и форма обратной связи
├── pyproject.toml    # Настройки проекта (Poetry)
└── poetry.lock
```

## Запуск сервера

1. Перейдите в папку проекта:

   ```bash
   cd my_website
   ```

2. Запустите сервер:

   ```bash
   python server.py
   ```

3. Откройте в браузере:

   ```text
   http://localhost:8080
   ```

## Функциональность страниц

- **Главная** — описание сайта и несколько карточек товаров с ценой и кнопкой «Купить».
- **Каталог** — список товаров (карточки с названием, ценой, описанием и кнопкой).
- **Категории** — карточки категорий с заглушками под изображения и кнопками `View/Edit`.
- **Контакты** — форма обратной связи (Имя, Почта, Сообщение) и блок «Наши контакты» с текстом.

## Цель проекта

Проект выполнен для обучения и закрепления материала:

- базовой вёрстке на Bootstrap (сетка, карточки, формы, кнопки);
- структурированию HTML‑страниц;
- работе с простым HTTP‑сервером на Python и раздачей статических файлов.
